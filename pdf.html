Tactical Command Trainer for DDIL Environments

Problem Statement ID: 26248
Domain: Defence & Cyber Security

This blueprint outlines a realistic, low-bandwidth, interactive training platform designed to train commanders to operate during Denied, Degraded, Intermittent, and Limited (DDIL) communications. It bridges physical electronic warfare realities with cognitive decision science.

01. The Core Issue: Information Starvation & Deception

Modern command platforms assume a continuous, high-speed internet/SATCOM link. However, during peer-conflict, adversaries execute Electronic Warfare (EW) jamming, GPS spoofing, and cyber attacks. This creates three critical failures in command operations:

1. Stale Tactical Maps

Positions freeze or update in bulk every 10–15 minutes. Commanders make decisions based on outdated target coordinates.

2. Partial Telemetry

Packet dropouts strip out key metadata like Friend-or-Foe (IFF) tags or fuel status, leading to misinterpretation.

3. Cyber Ghost Tracks

Injected fake C2 messages create false threat tracks, forcing commanders to waste strikes on non-existent targets.

The Problem with Current Training: Military commanders are accustomed to pristine digital displays during peacetime exercises. When faced with degraded displays, they experience Analysis Paralysis or make reckless assumptions.

03. Light Touch: Key Science & Concepts

We use two simple mathematical concepts to power the simulation without overloading system resources:

1. Gilbert-Elliott Network Model

Instead of predicting every radio wave, the channel flips between two dynamic states:

  • State G (Good): 99% packets pass smoothly.
  • State B (Bad): 95% packets dropped due to jamming.

Why it matters: It creates realistic "bursts" of network loss rather than simple random drops.

2. Subjective Logic (3-Part Trust Metric)

Instead of giving a simple probability (e.g., "80% chance enemy"), every target track is split into:

Opinion = [ Belief + Disbelief + Uncertainty = 1.0 ]

Why it matters: If satellite feeds drop, "Uncertainty" rises, signaling to the commander that data is missing, not that the target disappeared.
